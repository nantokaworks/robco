# 02 — Naming & Brand

## Locked naming spec

```
Name                  : RobCo
command / crate / repo : robco
Tagline               : Repo-Oriented Bot Control & Orchestration   (the R.O.B.C.O. backronym)
Casual reading        : "robot co-op"   (how people naturally read it)
help one-liner        : robco — control & orchestrate Claude agents across your repos
```

The tagline **is** a backronym of the name and doubles as the one-line description:

| Letter | Word |
|--------|------|
| **R** | **R**epo-Oriented |
| **O** | **O**riented *(part of "Repo-Oriented")* |
| **B** | **B**ot |
| **C** | **C**ontrol |
| **O** | **O**rchestration |

`Repo-Oriented` follows the established `X-Oriented` pattern (object-oriented,
service-oriented) and encodes the project-first design principle directly in the name.
`Control` (you steer agents) and `Orchestration` (the tool coordinates them) carry
distinct meaning, so the phrase reads naturally rather than as filler.

## Aesthetic

A **retro green-phosphor terminal** look — boot sequence, monospace, a `ROBCO` header.

```
ROBCO ▸ repo-oriented bot control & orchestration
// OVERSEER TERMINAL
```

The aesthetic is *inspired by* classic computer terminals. It is intentionally generic
and uses no third-party brand assets.

## Legal line (not legal advice)

The **name is fine**. To stay clear of any third-party trademark/copyright:

- Do **not** use the marks/names **Vault-Tec, Pip-Boy, Fallout, Vault Boy**, or any
  associated logos.
- Do **not** copy any third-party logos, artwork, sounds, or **verbatim in-game text**
  (e.g. do not reproduce a real product's exact boot-screen string).
- Keep the retro-terminal aesthetic **generic / "inspired by"**, authored from scratch.
- Reasoning: a short name is not copyrightable; trademark turns on confusion within a
  market, and a free developer CLI is a different category from any game — but leaning on
  recognizable owned marks/art is what creates risk, so we avoid those specifically.
- If the project is ever commercialized or grows large, get a proper trademark
  clearance / legal review at that point.
